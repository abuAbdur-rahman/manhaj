# Security Policy

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities. Use GitHub's private vulnerability reporting feature on this repository instead.

Include the affected route or component, reproduction steps, impact, and any suggested mitigation. Reports will be acknowledged within seven days.

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Secrets

Do not include credentials, tokens, private URLs, user data, or production configuration in issues, pull requests, logs, or screenshots.
